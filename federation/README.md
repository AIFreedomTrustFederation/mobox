# AIFT Mobox Federation Layer

`mobox` remains the mobile workstation soil: a Termux/Android environment capable of running powerful local tools from ordinary mobile hardware.

This `federation/` layer defines how AI Freedom Trust Federation concepts grow on top of that soil without disrupting upstream Mobox behavior.

## Role

**AIFT Mobox** is the mobile-first workstation for underconnected, low-resource, and field-based Federation members.

It should eventually support:

- local-first onboarding
- Living Node exploration
- Tree of Life / forest visualization
- local AI Gardener agents
- bounties and Proof-of-Learning cultivation
- Scroll reading, writing, validation, and synchronization
- Mysterion knowledge-base access by permissioned agent level
- federation maps, seed drops, local tribes, and cooperative growth

## First Federation Principle

The system begins with people who have the least access to money, hardware, institutions, and technical infrastructure.

If AIFT Mobox can serve them, it can serve everyone.

## Build Direction

AIFT Mobox should grow through this pattern:

```text
Scroll doctrine
→ machine-readable schemas
→ TypeScript contracts
→ local AI agents
→ consent records
→ visual Tree/Map projections
→ verified bounties
→ Federation events
```

The mobile workstation is the soil. The Living Node engine is the seed. The Tree of Life interface is the first visible sprout.
